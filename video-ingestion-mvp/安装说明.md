# 安装说明

这是全新安装流程，不保留旧数据库数据。安装时只需要选择素材存储目录，AI Key 和模型可以进入系统后再配置。

安装需要联网下载项目专用 Node.js、项目依赖和 FFmpeg。下载内容会放在项目目录下，不会安装到系统全局环境。

## 安装前确认

- 电脑需要能联网。
- 素材存储目录不要选择系统目录、用户主目录或项目代码目录。
- 如果选择的素材存储目录已经有文件，安装器会自动创建一个新的 `VideoIngestionStorage-*` 子目录使用，不会删除已有文件。
- 这是全新安装；旧的 `prisma/dev.db` 会被重建。

## Windows

双击：

```text
安装-windows.bat
```

安装完成后双击：

```text
启动-windows.bat
```

## macOS

双击：

```text
安装-mac.command
```

如果系统提示无法打开，可以在终端进入项目目录后执行：

```bash
chmod +x 安装-mac.command 启动-mac.command install/*.sh
./安装-mac.command
```

安装完成后双击：

```text
启动-mac.command
```

## Ubuntu / Linux

进入项目目录后执行：

```bash
chmod +x install/*.sh 安装-mac.command 启动-mac.command
./install/bootstrap-mac-linux.sh
```

安装完成后启动：

```bash
./install/start-mac-linux.sh
```

也可以直接使用项目自带 npm 启动：

```bash
.runtime/node/bin/npm run start
```

开发调试时使用：

```bash
.runtime/node/bin/npm run dev
```

## 安装器会自动处理

- 下载项目专用 Node.js 到 `.runtime/node`
- 安装项目依赖
- 安装项目专用 FFmpeg / ffprobe
- 生成 `.env`
- 自动生成 `AUTH_SECRET`
- 重建全新 SQLite 数据库
- 初始化默认工作区
- 创建初始超级管理员并在安装完成时显示用户名和密码
- 检查安装环境
- 构建系统

## 初始超级管理员

安装完成页会显示初始超级管理员：

```text
用户名：admin
密码：安装器生成的随机密码
```

首次登录后系统会要求修改密码。AI Key、模型、存储巡检等设置可以登录后再配置。

如果忘记密码，可以在项目目录执行重置脚本，生成新的临时密码：

```bash
.runtime/node/bin/node - <<'NODE'
require('sucrase/register');
const { PrismaClient } = require('@prisma/client');
const { hashPassword, generateReadablePassword } = require('./lib/auth/password.ts');
const prisma = new PrismaClient();

async function main() {
  const password = generateReadablePassword(18);
  const user = await prisma.userAccount.update({
    where: { username: 'admin' },
    data: {
      passwordHash: await hashPassword(password),
      role: 'SUPER_ADMIN',
      status: 'ACTIVE',
      mustChangePassword: true
    },
    select: { id: true, username: true, role: true }
  });
  await prisma.userSession.deleteMany({ where: { userId: user.id } });
  console.log({ username: user.username, password, role: user.role });
}

main().finally(async () => prisma.$disconnect());
NODE
```

## 权限说明

| 角色 | 可以做什么 |
| --- | --- |
| 超级管理员 `SUPER_ADMIN` | 使用所有功能，包括系统设置、AI 设置、存储根目录、栏目/目录管理、系统维护、系统重置和用户管理。 |
| 管理员 `ADMIN` | 管理普通用户，上传和管理素材，删除到回收站，恢复素材，确认入库，重分析，设备导入，管理拍摄人。不能改系统高危设置。 |
| 普通用户 `USER` | 上传文件，只读查看素材库，可以预览和下载已入库素材。不能删除、移动、改名、编辑标签、确认入库、重分析或改设置。 |

## 常见问题

### 访问不了系统

确认启动窗口没有关闭，并访问：

```text
http://localhost:8888/login
```

如果提示端口被占用，先关闭其他正在运行的本系统窗口，再重新启动。

### `.env` 里没有初始密码

如果不是通过安装器安装，或者账号已经初始化过，系统不会再显示旧密码。忘记密码时使用上面的重置脚本。

### `check:env` 有存储目录警告

如果提示直接写入检查被拒绝，但 POSIX 权限显示可写，可以在目标机器上重新运行：

```bash
.runtime/node/bin/npm run check:env
```

只要系统能正常上传和生成文件，一般不影响使用。

### AI 还没配置

默认 `AI_PROVIDER=mock`，可以先跑通上传、入库和素材库流程。登录后再进入系统设置配置真实 AI Key 和模型。

## 不要提交这些文件

不要提交真实 `.env`、API Key、SQLite 数据库、数据库备份、真实素材文件、`.runtime`、`.next`、`node_modules`。
